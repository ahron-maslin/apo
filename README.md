# apo

apo (AI Project Orchestration) is a local dashboard and MCP server for Claude Code. Your agents ask instead of stopping, you answer every project's questions from one queue, and the answer lands in the repo where the next session picks it up.

It isn't released yet. This version only holds the name on PyPI, and installing it gives you a command that says so.

Follow along at https://getapo.pages.dev/
